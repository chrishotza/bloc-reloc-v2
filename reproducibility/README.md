# Reproducibility / Reproducibilidad

This repository contains **both recorded historical experiment artifacts and scripts for new local runs**. These are different evidence layers; do not assume every committed CSV was regenerated by the current minimal runner.

Este repositorio contiene **resultados históricos archivados y scripts para nuevas ejecuciones locales**. No todos los CSV publicados se regeneran con el script mínimo actual.

## Archived versus generated material / Material archivado y generado

| Location | Meaning |
| --- | --- |
| [`results/`](../results/) | **Tracked** CSVs, plots and observatory reports from earlier studies, including the six-configuration dynamics synthesis |
| `data/graphs/` | **Untracked** synthetic pickle fixtures generated locally; deliberately excluded via `.gitignore` |
| [`experiments/run_generation.py`](../experiments/run_generation.py) | Synthetic graph creation using four graph families and seeds 0–29 |
| [`experiments/run_experiment.py`](../experiments/run_experiment.py) | Minimal runner currently comparing **baseline** against **affinity_modified** only |
| [`EXPERIMENT_PLAN.md`](EXPERIMENT_PLAN.md) | Broader research protocol; **a plan, not evidence that every listed variant was run** |

## Minimal local procedure / Procedimiento mínimo local

From the repository root, with Python and NetworkX installed:

```bash
python -m pip install networkx
python -m experiments.run_generation
python -m experiments.run_experiment
```

The generator creates `data/graphs/` under the repository root. The runner reads those graphs, uses its own fixed algorithm seed, and writes `results/bloc_reloc_v2_results.csv`.

**Preserve evidence:** The results CSV is tracked by Git. The minimal runner **overwrites** it; use a clean working copy or a dedicated branch before running. Do not commit newly generated results as if they were the historical benchmark without identifying the new protocol.

**Security:** Python pickle is not safe for untrusted files. Only open graph pickles created by the local generator or received from a source you trust.

## Scientific boundary / Alcance científico

- The archived [final synthesis](../results/observatory/final_synthesis/BLOC_RELOC_V2_FINAL_SYNTHESIS.md) reports six historical configurations but does **not** constitute a fresh rerun by the minimal two-variant script.
- Runtime measurements depend on machine, environment and workload. Repeated local runs are needed to establish variance.
- Some higher-level planned comparisons (external solvers, additional ablations, real graph families) require separate validated entrypoints and provenance; do not infer completion merely from the experimental plan.
- Keep source code, seeds, input graphs, output hashes and hardware/environment notes together when publishing a new independent result.

The intention is to make the boundary between **what can be reproduced now** and **what was recorded earlier** explicit.
